## How it works

<CardGrid>
  <Card title="1. Label an issue ready" icon="approve-check">
    Tag a GitHub issue as `ready` in your backlog. That is the whole handoff.
  </Card>
  <Card title="2. An agent claims it and opens a pull request" icon="pencil">
    An agent picks the issue up, implements the change, and opens a pull request for you to see.
  </Card>
  <Card title="3. Review and merge happen without you" icon="rocket">
    A separate reviewer checks the work and merges it. Decisions that need you reach you, optionally over Telegram.
  </Card>
</CardGrid>

## Who it is for

<CardGrid>
  <Card title="Solo maintainers with a long backlog" icon="list-format">
    Agents claim your `ready` issues, implement them, and merge the results while you set the direction.
  </Card>
  <Card title="Small teams that want async delivery" icon="laptop">
    Drive and intervene remotely over Telegram instead of watching an interactive terminal.
  </Card>
  <Card title="Anyone already paying for a backend CLI" icon="setting">
    my-ai-team runs on top of the CLI you already pay for — it does not replace it, and you keep using your own account.
  </Card>
</CardGrid>
